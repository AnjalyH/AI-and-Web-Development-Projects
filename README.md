# AI & Web Development Projects

This repository contains three programming projects developed as part of an academic assignment.

## Projects

### 1. Login and Registration System

A web-based authentication system that allows users to register and log in using their credentials.

**Technologies:**
- HTML, CSS and JavaScript
- Node.js and Express.js
- SQLite Database

**Features:**
- User registration
- User login
- Password hashing
- Database storage
- Session-based authentication

Folder: `Login-Registration/`

### 2. AI Document Assistant (LLM & RAG)

An AI-powered application that uses Retrieval-Augmented Generation (RAG) to answer questions based on uploaded PDF documents.

**Technologies:**
- Python
- Streamlit
- LangChain
- Google Gemini
- FAISS
- PyPDF

**Features:**
- PDF document upload
- Text extraction and splitting
- Text embeddings
- Vector storage and retrieval
- AI-generated answers based on document content

**Live Application:**  
[Open AI Document Assistant](https://anjaly-ai-document-assistant.streamlit.app/)

Folder: `AI-Document-Assistant/`

### 3. Website Summarizer

A web application that accepts a website URL, extracts its content and generates a summary using an AI language model.

**Technologies:**
- Python
- Streamlit
- BeautifulSoup
- Google Gemini

**Features:**
- Website URL input
- Webpage content extraction
- AI-powered text summarization
- Summary display

**Live Application:**  
[Open Website Summarizer](https://anjaly-website-summarizer.streamlit.app/)

Folder: `Website-Summarizer/`

## Setup

Each project has its own folder and dependency file.

1. Open the required project folder.
2. Install the dependencies listed in its `requirements.txt` or `package.json`.
3. Configure the required environment variables in a local `.env` file.
4. Run the application using the instructions provided in that project's README.

**Note:** API keys, environment files, local databases and virtual environments are not included in this repository.
